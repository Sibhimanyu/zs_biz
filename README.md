# ZO Hotel: cancellation marketing

An exit prompt (Part A) and a landing page (Part B) for guests who book ZO Hotel Mumbai at short notice, built from an analysis of 20,337 cancellation records.

| File | What it is |
|---|---|
| `set5/landing.html` | Part B: landing page for last-minute guests |
| `set5/booking-confirmation.html` | Part A: exit prompt (choose "Cancel booking instead") |
| `set5/slides/deck.html` | Slide deck: the data, the logic, the style guides |
| `set5/zo-hotel.html` | The full ZO Hotel site, for context |
| `set5/analysis/late_cancellations.py` | Reproduces the numbers in `results.json` |

The analysis script reads the bookings CSV, which is not included in this repository.

ZO Hotel is a fictional brand for educational use. The reviews on the landing page are samples.
